# 👋 About Me — Portfolio

My personal portfolio site, showcasing my background, experience, and data analytics projects.

🔗 **Live site:** [yuvrajabdullah99.github.io/About-Me](https://yuvrajabdullah99.github.io/About-Me/)

## What's Inside

- **Home** — intro, education, work experience, and technical skills
- **Projects** — Kmart Sales Dashboard, Everyday Rewards Loyalty Dashboard, Woolworths Dark Store Shelf Planner, Blackmores HR Analytics Dashboard, and Netflix Viewing Analytics, each with its own dedicated project page
- **Resume** — downloadable PDF linked from the nav bar
- Dark/light mode toggle

## Built With

- HTML, CSS, and vanilla JavaScript
- Font Awesome for icons
- Hosted on GitHub Pages

## Running Locally

Clone the repo and open `index.html` directly in a browser — no build step required.

```bash
git clone https://github.com/yuvrajabdullah99/About-Me.git
cd About-Me
open index.html
```
